# File catalog

Searchable catalog of **important** files. Columns: path · responsibility · key symbols ·
inputs → outputs · notable dependencies · related tests · related feature (see
[`FEATURE_TO_FILE_MAP.md`](FEATURE_TO_FILE_MAP.md)). Paths are repository-relative and are
verified by `scripts/validate_brain.py`. Trivial/generated files are grouped at the end.
Navigation: [`../README.md`](../README.md) · [`REPOSITORY_MAP.md`](REPOSITORY_MAP.md).

A `::` token means "file and symbol"; the audit script resolves the symbol with Python's AST.
